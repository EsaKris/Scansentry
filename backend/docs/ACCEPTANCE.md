# Acceptance scenarios (PRD section 20)

Status of every scenario the PRD says must work before the MVP is called complete. **"Backend verified"** means automated tests prove the
API does it. It does **not** mean the web or Android screen exists: those clients are not built yet, so no scenario is complete end-to-end
for a human until its client work is done. Test references are checked by `tests/test_acceptance_map.py` (a missing test fails the suite).

(see `docs/SANDBOX_TESTING.md`).
